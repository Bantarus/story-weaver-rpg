# AI Flows (Genkit)

The application uses Genkit to orchestrate interactions with generative AI models. Flows are defined as server actions and are responsible for different stages of the RPG content generation. All flows are located in `src/ai/flows/`.

The global Genkit instance is configured in `src/ai/genkit.ts` using the Gemini model.

## 1. `analyzeSourceMaterial`

-   **File:** `src/ai/flows/analyze-source-material.ts`
-   **Purpose:** To analyze the user-provided story text and extract key literary elements. This helps in understanding the source material for subsequent generation steps.
-   **Input (`AnalyzeSourceMaterialInput`):**
    -   `storyText` (string): The raw narrative text provided by the user.
-   **Output (`AnalyzeSourceMaterialOutput`):**
    -   `plotPoints` (string): Key plot points.
    -   `characters` (string): Important characters identified.
    -   `settings` (string): Key settings and locations.
    -   `themes` (string): Underlying themes.
    -   `tone` (string): Overall tone and style.
-   **Logic:**
    -   Uses a Genkit prompt (`analyzeSourceMaterialPrompt`) that instructs the AI to act as a literary analyst and extract the specified elements from the `storyText`.
    -   The output is expected as a JSON object matching `AnalyzeSourceMaterialOutputSchema`.

## 2. `generateNarrativeOutline`

-   **File:** `src/ai/flows/generate-narrative-outline.ts`
-   **Purpose:** To create a narrative outline that integrates the user's custom character into the provided story.
-   **Input (`GenerateNarrativeOutlineInput`):**
    -   `storyText` (string): The original story text.
    -   `characterDescription` (string): A description of the player's character (name, archetype, background, goals).
-   **Output (`GenerateNarrativeOutlineOutput`):**
    -   `narrativeOutline` (string): A textual outline describing how the character's journey might unfold within the story, including challenges, encounters, and potential resolutions.
-   **Logic:**
    -   Uses a Genkit prompt (`generateNarrativeOutlinePrompt`) that instructs the AI to weave the `characterDescription` into the `storyText`, producing a compelling narrative structure.
    -   The output is expected as a JSON object matching `GenerateNarrativeOutlineOutputSchema`.

## 3. `formatGameDataJson`

-   **File:** `src/ai/flows/format-game-data-json.ts`
-   **Purpose:** To transform the high-level `narrativeOutline` into a detailed, structured JSON object that the game engine (the `/play` page) can directly consume to render the interactive RPG.
-   **Input (`FormatGameDataJsonInput`):**
    -   `narrativeOutline` (string): The narrative outline generated by the previous flow.
-   **Output (`FormatGameDataJsonOutput`, which is `AIGameDataSchema`):**
    -   `title` (string, optional): Overall title for the adventure.
    -   `startSceneId` (string): The ID of the initial scene.
    -   `scenes` (array of `AISceneNode`): A list of all game scenes. Each `AISceneNode` includes:
        -   `id` (string): Unique scene identifier.
        -   `title` (string, optional): Title for the scene.
        -   `text` (string): Narrative text for the scene.
        -   `choices` (array of `SceneChoice`): Player choices leading to other scenes.
        -   `isEnding` (boolean, optional): True if it's an ending scene.
        -   `endingType` (string, optional): Type of ending (e.g., "victory", "tragedy").
        -   `visualHint` (string, optional): Suggestion for visual elements.
        -   `soundEffect` (string, optional): Suggestion for sound effects.
-   **Logic:**
    -   Uses a Genkit prompt (`formatGameDataJsonPrompt`) that provides detailed instructions and the schema for the desired JSON structure. It emphasizes the need for branching narratives, unique scene IDs, and correct linkage between choices and `nextNodeId`.
    -   The AI is instructed to produce `scenes` as a JSON array.
    -   **Post-processing within the flow:**
        -   The raw text output from the LLM is cleaned (whitespace, Markdown fences stripped).
        -   The cleaned text is parsed into a JavaScript object.
        -   It handles cases where the AI might (incorrectly) return `scenes` as an object map instead of an array, converting it if necessary.
        -   The `startSceneId` is validated, and a default is chosen if the provided one is invalid.
        -   The final output adheres to `AIGameDataSchema` (where `scenes` is an array). The client-side code in `/create/page.tsx` then transforms this array into a record for `GameContext`.
