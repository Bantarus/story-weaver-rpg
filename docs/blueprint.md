# **App Name**: Story Weaver RPG

## Core Features:

- Source Material Analysis: Analyzes user-provided story text to identify key plot points, characters, settings, themes, and tone.
- Narrative Outline Generation: Generates narrative outlines based on integrated player characters. Considers challenges, encounters, climaxes and resolutions. It acts as a tool to combine character background and goals.
- Structured Game Data JSON Formatting: Formats the narrative outline into a detailed JSON object with game scenes, descriptive text, choices, and transitions, creating structured game data.
- Interactive Narrative Display: Presents narrative text and choices from the current scene. Allows players to navigate to subsequent scenes based on their selections.

## Style Guidelines:

- Primary color: HSL(50, 80%, 50%) - A vibrant, warm yellow (#F0BA29) to evoke a sense of adventure and classic storytelling.
- Background color: HSL(50, 20%, 95%) - Very light yellow (#FDFDF0), almost white, providing a neutral backdrop that ensures readability while maintaining a connection to the primary color's theme. Using light mode.
- Accent color: HSL(20, 70%, 40%) - A rich, slightly desaturated orange (#B85D29) that complements the yellow, used for interactive elements and to highlight key choices and information.
- Clean, serif font for body text to enhance readability and evoke a sense of traditional storytelling.
- Text-focused layout with clear separation between the narrative and player choices.
- Subtle transitions between scenes.
